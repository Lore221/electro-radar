# Отдельная сеть перехвата

## Problem Statement
Контроллеры перехвата подключены к радарной сети и выбирают угрозы нескольких Alarm.
Зона копируется из предмета, поэтому сам Выделитель не принадлежит прибору.

## Solution
Shell Alarm остаётся потребителем радарной сети и владеет отдельной сетью перехвата.

## User Stories
1. Игрок подключает Alarm к радарной сети обычным linker.
2. Первый ПКМ linker по Alarm работает с радарной сетью, второй копирует сеть перехвата;
   повторные клики чередуют сети. Другой прибор сбрасывает последовательность.
3. Shift+ПКМ в воздух очищает выбор и последовательность. Shift+ПКМ по Alarm отключает
   его радарное подключение; собственная сеть перехвата сохраняется.
4. К сети перехвата подключаются только контроллеры перехвата; радарные приборы её не принимают.
5. Предмет контроллера копирует сеть перехвата с Alarm и сохраняет её при установке.
6. Подсветка сети перехвата пульсирует между жёлтым и оранжевым; радарная остаётся голубой.
7. ПКМ Выделителем с готовой зоной вставляет его в единственный слот Alarm.
   Занятый слот отклоняет вставку. Shift+ПКМ пустой рукой извлекает предмет.
8. При разрушении Alarm вставленный предмет выпадает. Выгрузка чанка его не выбрасывает.
9. Без Выделителя зоны нет; без зоны или радарной связи контроллер не стреляет.
10. Сети, подключения и вставленный предмет сохраняются после загрузки мира.
11. Старые контроллеры переподключаются вручную; старые скопированные зоны не создают предметов.

## Implementation Decisions
Радарный менеджер сохраняет единственную регистрацию Alarm. Сеть перехвата имеет отдельный
реестр загруженных владельцев и контроллеров. Контроллер получает цели через владельца,
который повторно проверяет текущее разрешение радарной сети перед выстрелом.
Тип привязки хранится вместе с ID в предмете и проверяется при работе linker и установке.
Старый ключ радарного подключения контроллера игнорируется при загрузке.

## Testing Decisions
Согласованные поверхности: принадлежность владельцев/контроллеров и изоляция сетей;
последовательности действий linker; сохранение и возврат предмета. Тесты проверяют
наблюдаемое поведение публичных методов. Игровая приёмка дополнительно проверяет
руки, события кликов, выпадение предмета и отображение цветов.

## Out of Scope
Автоматическая миграция старых контроллеров, GUI слота, распределение целей между пушками.
